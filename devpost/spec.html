Paperclear

Technical Specification — Electron + Gemini AI

How This Works

In plain language

PaperclearはElectronという仕組みでHTML/CSS/JavaScriptをデスクトップアプリの「箱」に入れたものです。

書類の写真をアプリに入れると、その画像データがGoogleのGemini APIに送られます。GeminiはAIで、画像を読んで「何をすべきか・いつまでに・どうやって」を取り出し、日本語と英語の両方でテキストとして返してきます。アプリはそのテキストを画面の右側に表示します。

APIキーはあなたのパソコンの中だけに保存されます（AppData内）。プロジェクトフォルダにも、GitHubにも入りません。

Core Journey Through the System

Step by step

1
起動 → APIキー確認 userData/config.jsonを読む。なければSetup画面へ。キー保存時にGeminiにテスト通信。
2
初期画面 → 写真選択 ドラッグ or ファイルピッカー → RendererがMainにIPC送信
3
Gemini API呼び出し gemini.jsが画像(base64) + プロンプトを送信。モデル名は定数1か所で管理。
4
JSONレスポンス → 画面描画 期限ブロック（朱色）→ 3行が animation-delay で順番に表示
5
言語切り替え メモリ内のJP/ENデータを切り替えるだけ。APIへの再通信なし。

Components

⚙️  main.js — Electronメインプロセス

アプリ起動・ウィンドウ生成・ファイルシステムアクセス・IPC受信を担当。

APIキーの読み書きはここで行う（Rendererは直接ファイルに触れない）。

prd.md > Settings, API Key Setup Screen

🔌  preload.js — セキュリティブリッジ

contextBridgeでRendererからMainへの安全なAPIを公開。Electronのセキュリティ設計上必須。

🔑  setup.html / setup.js — APIキー入力画面

マスク入力・表示切り替え（目アイコン）・「保存して始める」ボタン。Mainにキー検証と保存を依頼。

prd.md > API Key Setup Screen

🏠  index.html / renderer.js — メインアプリ（シングルページ）

初期画面・処理中・結果・設定のすべてをここで管理。画面状態（home / loading / result / settings）に応じてHTML表示を切り替える。

prd.md > Initial Screen, Processing Screen, Result Screen, Settings Screen

🤖  gemini.js — Gemini API通信

モデル名・プロンプトをここに集約。画像(base64)+プロンプト → Gemini → JSONパース → 構造化データを返す。

prd.md > Document Reading

期待するJSONレスポンス:

"deadline": "10月31日",
"days_remaining": 23,
"ja": { "what": "...", "by_when": "...", "how": "..." },
"en": { "what": "...", "by_when": "...", "how": "..." }
💾  config.js — APIキー管理

読み書き先: app.getPath('userData')/config.json（例: C:\Users\username\AppData\Roaming\Paperclear\）

プロジェクトフォルダ外のため .gitignore への追記不要。

prd.md > Product Decisions（APIキー保存）

Data Model

データ保存場所アプリを閉じると
APIキーuserData/config.json残る
言語設定メモリ（JS変数）リセット（日本語）
読み取り結果（JP/EN）メモリ（JS変数）消える
書類写真メモリ（ObjectURL）消える

Important Failure Modes

  • !APIが遅い・タイムアウト → 「読み取りに失敗しました。もう一度お試しください」＋リトライ
  • !無料枠の上限（429エラー） → 通信エラーと区別して「利用回数の上限に達しました。少し待ってからお試しください」
  • !書類ではない画像 → JSONパース失敗 or 期限空 → 「書類を読み取れませんでした」＋「別の写真を選ぶ」
  • !APIキー無効 → セットアップ画面でテスト通信失敗 → 「鍵が正しくないようです」、画面に留まる
