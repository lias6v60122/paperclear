Core Journey

End-to-end flow

1
First launch — API key setup Enter Gemini API key → validate with test call → save locally → proceed to app
2
Initial Screen Large drop zone with guide text · drag-and-drop or file picker · language toggle top-right
3
Processing Layout splits left/right · scanning animation over photo · placeholder lines on right
4
Result — the "oh, that's useful" moment Vermilion deadline block at top · 3 action lines appear one-by-one · photo stays left for comparison
5
Language switch (any time) Toggle switches やさしい日本語 ↔ English instantly — no re-read required
6
Next document "別の書類を読む" button → back to Initial Screen

Screens & Layout

🔑  API Key Setup Screen — first launch only
  • Short explanation: "書類を読むために、Geminiの鍵が必要です"
  • Masked text input with eye icon (show/hide toggle)
  • "鍵の取得方法を見る" link — opens Google's official API key page in system browser
  • "保存して始める" button — validates key with test call before saving
  • On success: key saved locally → navigate to Initial Screen
  • On failure: inline error "鍵が正しくないようです。もう一度確認してください" — stay on screen
🏠  Initial Screen
  • Top-left: App name + logo (small)
  • Top-left (near logo): Settings gear icon (small, unobtrusive)
  • Top-right: Language toggle — やさしい日本語 / English
  • Center: Large drop zone — envelope/document illustration + 2-line guide text
  • Below drop zone: "写真を選ぶ / Choose photo" button
  • No other menus, navigation, or settings visible
⏳  Processing Screen
  • Left panel: Uploaded photo, full height
  • Right panel: "書類を読んでいます… / Reading document…" + 3 soft placeholder lines
  • Animation: Thin light line sweeps top→bottom over the photo
  • Language toggle remains active; no other input accepted
✅  Result Screen
  • Left panel: Photo (unchanged)
  • Right panel — top: Vermilion deadline block — e.g. "10月31日まで（あと23日）"
  • Right panel — below deadline: 3 action lines appear one-by-one
    • 何を / What: [action]
    • いつまでに / By when: [date]
    • どうやって / How: [method]
  • Top-right: Language toggle — switches instantly, no re-read
  • Bottom-right: "別の書類を読む / Read another document" button
⚙️  Settings Screen
  • Accessed via gear icon on Initial Screen
  • "鍵を変更する / Change key" — opens API Key Setup Screen flow
  • "鍵を削除する / Delete key" — removes saved key; next launch shows API Key Setup Screen

Normal launch Proceeds directly to Initial Screen

Result — success Deadline + 3 lines as described
No deadline "期限は見つかりませんでした" in deadline area · partial 3-line summary shown
Non-document image "書類を読み取れませんでした" + "別の写真を選ぶ" button

Invalid API key (setup) Inline error · stay on setup screen
