Scope · Approved

Paperclear

A desktop app that reads official Japanese documents and tells you what to do, by when, and how.

The Unique Kernel

Translation apps translate text. Paperclear tells you what to do. It turns a wall of bureaucratic Japanese into a 3-line action instruction with the deadline made impossible to miss. The output isn't a reading — it's a to-do.

Core Loop

🧑‍💼
Foreign resident / family helper
Gets an official envelope. Can't parse it.
→
📷
Photo in
Drop one image into the app
→
🤖
Gemini reads it
Extracts action + deadline
→
✅
3-line action + deadline
Plain Japanese or English, their choice

What "Working" Looks Like

  • ✓Deadline appears large at the top — e.g. "10月31日まで（あと23日）"
  • ✓3 action lines: 何を / いつまでに / どうやって
  • ✓Toggle switches the output between plain Japanese and English
  • ✓Original photo visible alongside the result
  • !No deadline found → "期限は見つかりませんでした"
  • !Not a document → "書類を読み取れませんでした"

Inspiration & Design Direction

🗂️
Theme
"A paper document, neatly sorted out." Calm and trustworthy — not tech-flashy.
Color palette
Washi off-white background · ink-black text · vermilion for deadlines only — like a red hanko stamp.
🔴
Deadline display
Largest element on screen, in vermilion — unmissable, like an urgent sticky note.
🖋️
Typography
Mincho (serif) for headings · Gothic (sans-serif) for body. Japanese document feel.
✨
Animation
3 action lines appear one by one in sequence after the photo is processed.
⬜
Spacing
Generous whitespace. Never pack information into a single screen.
Avoid Purple gradients, dashboard boilerplate, generic template aesthetics.

POC Boundary, Later & Cut

✅  In scope (POC)
  • Photo input
  • Gemini API call to read the document
  • 3-line action summary (what / by when / how)
  • Deadline display
  • Plain Japanese / English language toggle
  • Graceful error states (no deadline, non-document image)
  • Fictional demo documents only — no real personal data
  • API key stored locally, never committed to the repo
🔜  Later
  • Support for other document types (tax, school, medical)
  • Copy-to-clipboard for the summary
  • History of previously scanned documents
  • Mobile version
✂️  Explicitly cut
  • Document storage & sharing — not needed to prove the core loop; adds complexity and privacy concerns
  • User accounts — no login needed for a local desktop tool
  • Application filing / form-filling — this app reads, it does not act
  • Legal or tax advice — summarizes procedures only, not legal obligations
